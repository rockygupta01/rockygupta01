## 🏗️ What I Build

### 📱 MEFABZ Scanner — Invoice Voice Reader
**Production Android App** · [Play Store →](https://play.google.com/store/apps/details?id=com.mefabz.scanner)

> Scans invoices with a camera, extracts product data via OCR, and reads it aloud — so warehouse workers keep their hands free.

**The Problem:** Amazon sellers processing 100+ items/day were manually re-typing invoice data, causing errors and slowing throughput.

**The Solution:** An offline-first Android app that uses ML Kit OCR + Android TTS to convert physical invoices into automated voice output in real time.

```
Stack: Kotlin · Jetpack Compose · ML Kit OCR · Android TTS
```

**Impact:**
- ⚡ Cuts manual data entry time for invoice processing
- 📦 Deployed in live Amazon seller inventory workflows
- ♿ Improves accessibility for eyes-free warehouse use
- 🔌 Offline-first — works without internet

---

### 🖨️ FN SKU Printer — Label Automation
**Production Android App** · [Play Store →](https://play.google.com/store/apps/details?id=com.tscprinter.fnsku)

> Generate and print Amazon FNSKU labels directly from your phone via Bluetooth to thermal printers.

**The Problem:** Sellers had to switch between laptop, label software, and printer — a 3-step workflow that broke flow in high-volume labeling.

**The Solution:** A lightweight mobile app with direct Bluetooth thermal printer integration (TSC-compatible), built to run on low-end Android devices in warehouse environments.

```
Stack: Kotlin · Android SDK · Bluetooth API · TSC Thermal Printer SDK
```

**Impact:**
- 🏷️ Single-tap label printing from phone → printer
- 📦 Designed specifically for Amazon FBA prep workflows
- 🔋 Optimized for low-end devices and warehouse conditions
